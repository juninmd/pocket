# Contributing to Firefox Pocket-like Extension

Thank you for your interest in contributing!

## Getting Started

1.  **Fork** the repository.
2.  **Clone** your fork.
3.  Install dependencies:
    ```bash
    cd firefox-pocket-extension
    pnpm install
    ```

## Development

- **Build (Dev):** `pnpm run build`
- **Build (Prod):** `pnpm run build:prod`
- **Test:** `pnpm test`

## Guidelines

- **Code Style:** Follow the existing TypeScript and React patterns.
- **Testing:** New features and bug fixes must include tests. We aim for 100% coverage.
- **Commits:** Use clear, descriptive commit messages.

## Pull Requests

- Open a PR against the `main` branch.
- Fill out the PR template.
- Ensure CI passes.
