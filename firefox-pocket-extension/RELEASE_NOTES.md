# Notas de Lançamento v1.0

Esta é a versão 1.0 (Final) da extensão Pocket-like para Firefox.

## Novidades

- **Lançamento Oficial:** Todas as funcionalidades principais foram implementadas e testadas.
- **Interface Localizada:** UI completa em Português do Brasil.

## Funcionalidades Incluídas

### 📥 Salvar e Gerenciar
- Salve páginas com um clique.
- Menu de contexto para salvar links rapidamente.
- Extração automática de metadados (Título, Imagem, Autor, Tempo de Leitura).

### 📖 Leitura
- **Modo Leitor:** Leia artigos sem distrações (anúncios, menus, popups).
- **Text-to-Speech (TTS):** Ouça seus artigos enquanto faz outras coisas.

### 🤖 Inteligência Artificial (Gemini)
- **Resumo Automático:** Gere sumários em bullet points de qualquer artigo salvo.
- **Chat Contextual:** Converse com a IA sobre o conteúdo do artigo que está lendo.
- **Extração de Conceitos:** Identifique termos chave e definições automaticamente.
- **Organização Automática:** A IA sugere pastas e tags para organizar sua biblioteca.

### 🗂️ Organização
- Sistema de Tags e Pastas.
- Favoritos e Arquivamento.
- Busca em tempo real.

### 🔒 Privacidade
- Todos os dados (artigos, imagens, configurações) são salvos no **Local Storage** do navegador.
- Nenhuma conta externa necessária (exceto API Key do Google para recursos de IA).

## Instalação

O arquivo empacotado está disponível em `web-ext-artifacts/pocket-like_extension-1.0.zip`.
